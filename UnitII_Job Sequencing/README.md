# Greedy Job Sequencing with Deadlines and Profits

## 📌 Project Overview

This project implements the Greedy Job Sequencing algorithm,
which schedules jobs with deadlines and profits to maximize
the total achievable profit.

## 🎯 Objectives

- Understand the Greedy algorithm paradigm
- Implement job sequencing
- Visualize the decision process
- Analyze time and space complexity

## 🧠 Algorithm

1. Sort jobs by decreasing profit.
2. Find the maximum deadline.
3. Create time slots.
4. For every job, search backwards from its deadline.
5. Assign the job to the latest available slot.
6. Calculate the total profit.

## 📊 Example

| Job | Deadline | Profit |
|-----|----------|--------|
| J1  | 2        | 100    |
| J2  | 1        | 19     |
| J3  | 2        | 27     |
| J4  | 1        | 25     |
| J5  | 3        | 15     |

## ✅ Result

Optimal schedule:

J3 → J1 → J5

Maximum Profit = 142

## ⏱ Complexity

Time: O(n log n + n*d)

Space: O(d)
